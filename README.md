Marine Odyssey

Marine Odyssey is a 2D underwater arcade survival game made in Unity.

You control a submarine travelling through the ocean while different threats spawn around you. Sharks can chase and hit you, sea mines can explode, starfish can damage you, and bigger events like the Kraken and its tentacles can show up and make things a lot harder.

You have a health bar, and you can collect health boosts to recover some health. The longer you survive, the higher your score gets.

There are also different random events, so the game isn't exactly the same every time you play. You can choose between WASD/Arrow Keys and Cursor Mode from the settings.

I started this project because I wanted to make an underwater game that was simple to play but still had enough random stuff happening to keep it interesting.
