# 🌊 Marine Odyssey

> Navigate the depths. Survive the ocean. Escape the impossible.

Marine Odyssey is a 2D endless survival game built in **Unity 6** for the **Stardance Game Jam**. Pilot a submarine through an ever-changing ocean while avoiding deadly predators, hiding from danger, and surviving large-scale environmental events.

---

## 🎮 Gameplay

You control a small submarine using the mouse as it travels through an endless ocean.

As you progress, the ocean becomes increasingly dangerous:

- 🦈 Sharks patrol the waters and chase you when they spot you.
- 🪸 Hide inside coral formations to escape predators.
- 🐙 Survive massive Kraken attacks as giant tentacles erupt from the ocean floor.
- ⭐ Dodge the upcoming Starfish Storm event.
- 🌊 Face even more ocean hazards as difficulty increases.

The objective is simple:

**Survive for as long as possible.**
